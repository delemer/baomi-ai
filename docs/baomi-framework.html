支撑层

决定"能做什么"的四层能力
AI 接入层
Max API 中转站一个 Key 覆盖 chat / 识图 / 生图 / 生视频 / 场景App / TTS
7 个媒体平台Atlas · fal · Replicate · 火山 · 百炼 · 硅基 · OpenAI
任意 OpenAI 兼容自填 baseUrl + 自定义模型，模型可自动发现
本地 Ollama完全离线跑开源模型
本地引擎层
FFmpeg合成、转场、字幕烧录、AIGC 元数据（兼容 FFmpeg 7+）
SQLite + 文件库项目 / 素材 / 成片全在本地 data 目录
Whisper 本地 ASR长素材转写、删词删静音剪片
内置中文字体自动规避中文安装路径导致的字体加载失败
扩展接口层
Windows 桌面端Electron 打包，内置 FFmpeg，双击即用
CLI / HTTP API脚本化批量出片、接自有系统
MCP / Agent Skill让 AI Agent 直接调用出片流水线
合规层
AIGC 显式标识片头「内容由 AI 生成」角标（可关，但会有风险提示）
AIGC 隐式标识写入 GB 45438 三项元数据，服务提供者=爆米AI
广告法扫描绝对化用语、违禁词在发布前拦截
发布门禁 + 署名发布前检查清单；第三方素材生成 credits

数据与交付

本地数据目录%APPDATA%\BaoMiAI\data —— sqlite.db / uploads / output；卸载前复制整个目录即可备份
分发形态Windows 安装包（NSIS）+ 开源仓库（完整源码，AGPL-3.0，可自行编译）
