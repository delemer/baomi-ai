爆款复刻 操作交互链路

工作台 → 爆款复刻：输入一条爆款参考 → 得到结构骨架 → 分两条路产出成片
1

输入爆款视频

三种输入，决定拿到的是「真实解析」还是「通用模板」

上传视频文件 真实解析

mp4 / webm / mov，≤80MB。
服务端用 ffmpeg 检测场景切点，得到真实镜头数 + 每镜时长。

POST /api/replicate/analyze (file)

粘贴视频直链 真实解析

以 .mp4 / .mov / .webm 结尾的直链。
服务端下载（SSRF 防护、≤80MB）后走同一套分析。

POST /api/replicate/analyze (url)

粘贴分享链接 不解析

抖音 / 快手 / 小红书分享页是反爬壳页，取不到播放地址。
只记为"参考来源"，按钮返回固定 6 段通用结构。

仅延迟 600ms 返回模板
载入结构参考
上传文件或直链 → 真实解析；分享链接 → 通用模板
↓
2

结构卡（决定后续两条路线是否可用）

卡片右上角徽标直接标明来源

参考视频真实镜头结构

真实解析

按画面切点得到节奏骨架（全长约 Xs）：逐镜对齐镜头数与时长，只复刻节奏、不照搬内容。

第 1 镜 · 3.8s第 2 镜 · 6.2s…按切点生成

→ 解锁：路线 A 的逐镜对齐 + 路线 B（若 ≤15s 且模型支持参考生视频）

爆款通用结构（参考）

通用模板

固定 6 段高转化骨架，AI 据此 + 你的商品重新写脚本（不依赖参考片画面）。

开场吸引 0-3s痛点放大 3-8s产品展示 8-15s 使用演示 15-25s效果对比 25-35s促销转化 35-40s

→ 只解锁：路线 A（不带真实节奏）；路线 B 不可用

3

上传你的商品

第 2 步出结构前，本步置灰不可操作

商品图片（1–5 张）

拖拽或点选上传，JPG / PNG。少图 → 画面可用素材少，保真重绘依赖它。

商品名称（必填）

两条路线都要求非空；也是项目命名来源（"{商品名} 复刻"）。

商品卖点

喂给脚本生成 / 模型级复刻提示词，决定"说什么"。

↓    分岔：两条出口    ↓
路线 A · 主路径

开始复刻生成（按节奏出脚本）

点底部主按钮 「开始复刻生成」 → 生成脚本后跳脚本页，继续走完整出片流程。

创建项目 + 上传商品图到该项目
POST /api/llm/script 生成脚本
targetDuration = 参考时长（夹在 15–40s）；真实解析时附 referenceStructure
跳转 /project/<id>/script
后续（在项目里继续）：判官团改稿 → 画面生成 → 配音 → 字幕 → 合成 → 多平台导出
路线 B · 一键成片

⚡ 一键成片复刻（模型级）

把参考视频 + 商品图直接交给 Seedance 参考生视频模型：保留运镜/节奏/景别，主体换成你的商品，一次调用出成片。

同样先创建项目 + 上传商品图
POST /api/ai/video（video-to-video）
参考视频 + 商品图；时长 = 参考时长夹在 4–15s；开音频
POST /replicate/save 落盘成片（provider 链接会过期）
直接产出：成片预览 → 「查看导出」→ /project/<id>/export
!

前置条件与拦阻

按钮置灰 / 报错都来自这几条
未配 LLM Key路线 A 直接报错「尚未配置 LLM，请先到设置填写 API Key」
未配视频模型路线 B 提示「需要配置视频模型（Max API + Seedance / Wan）」
模型不支持参考生视频路线 B 提示换成 Seedance 系列；路线 A 不受影响
参考视频 > 15 秒路线 B 按钮禁用（徽标提示）；路线 A 的节奏复刻照常
一句话：想快 → 路线 B（一条素材直接出片）；想可控 → 路线 A（拿节奏骨架去写脚本，再逐镜调）
